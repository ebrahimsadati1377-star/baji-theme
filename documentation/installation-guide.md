# راهنمای نصب قالب BajiStyle

## پیش‌نیازها

| مورد | نسخه حداقل |
|------|------------|
| وردپرس | 6.4 |
| PHP | 8.1 |
| WooCommerce | 8.0 |
| Node.js (برای build) | 18+ |

---

## مرحله ۱ — آپلود قالب

### روش اول: آپلود از پیشخوان
1. فایل zip قالب را از **ظاهر ← پوسته‌ها ← افزودن ← آپلود پوسته** آپلود کنید.
2. روی **نصب اکنون** کلیک کنید، سپس **فعال‌سازی**.

### روش دوم: آپلود مستقیم (FTP/SSH)
```
/wp-content/themes/bajistyle/
```

---

## مرحله ۲ — نصب WooCommerce

1. به **افزونه‌ها ← افزودن** بروید و WooCommerce را نصب/فعال کنید.
2. wizard راه‌اندازی اولیه را تکمیل کنید.
3. از **WooCommerce ← تنظیمات ← پیشرفته** صفحات پایه را بررسی کنید.

---

## مرحله ۳ — نصب فونت وزیرمتن

فایل‌های woff2 فونت را از مخزن رسمی `rastikerdar/vazirmatn` در گیت‌هاب دانلود
کرده و در مسیر زیر قرار دهید:

```
assets/fonts/vazirmatn/
├── Vazirmatn-Light.woff2
├── Vazirmatn-Regular.woff2
├── Vazirmatn-Medium.woff2
├── Vazirmatn-SemiBold.woff2
└── Vazirmatn-Bold.woff2
```

---

## مرحله ۴ — Build فایل‌ها (اختیاری)

فایل‌های آماده در قالب موجودند. برای توسعه:

```bash
cd wp-content/themes/bajistyle
npm install
npm run build   # build کامل CSS + JS
npm run dev     # watch mode برای توسعه
```

---

## مرحله ۵ — تنظیمات Customizer

از **ظاهر ← شخصی‌سازی**:

- **رنگ‌های برند**: طلایی (#C9A227)، مشکی (#111111)، کرم (#F8F5EF)
- **بخش هیرو**: عنوان، زیرعنوان، دکمه، تصویر پس‌زمینه
- **داستان برند**: عنوان، متن و تصویر
- **شبکه‌های اجتماعی**: اینستاگرام، تلگرام، واتساپ، پینترست
- **اطلاعات تماس**: شماره، ایمیل، آدرس، کپی‌رایت فوتر

---

## مرحله ۶ — تنظیم منوها

از **ظاهر ← منوها**:

| موقعیت | کاربرد |
|---------|---------|
| منوی اصلی | هدر دسکتاپ (مگامنو) |
| منوی موبایل | هدر موبایل |
| فوتر - درباره ما | ستون اول فوتر |
| فوتر - راهنمای خرید | ستون دوم فوتر |
| فوتر - ارتباط با ما | ستون سوم فوتر |

---

## مرحله ۷ — اسلایدر هیرو

از **اسلایدر هیرو** در پیشخوان:

1. اسلاید جدید اضافه کنید.
2. تصویر شاخص (پیشنهادی: ۱۹۲۰×۱۰۸۰) اضافه کنید.
3. در باکس «جزئیات اسلاید»: متن دکمه و لینک را وارد کنید.
4. با ترتیب صفحه (Page Attributes)، ترتیب نمایش را کنترل کنید.

---

## مرحله ۸ — تنظیم صفحه اصلی

1. یک صفحه جدید بسازید (مثلاً «خانه»).
2. از **تنظیمات ← خواندنی** → «یک صفحه ثابت» → صفحه اصلی را انتخاب کنید.
3. قالب به‌صورت خودکار از `front-page.php` استفاده می‌کند.

---

## مرحله ۹ — ویژگی‌های محصول (رنگ و سایز)

1. از **WooCommerce ← ویژگی‌ها** ویژگی‌های `color` و `size` را بسازید.
2. محصولات Variable را با این ویژگی‌ها تنظیم کنید.
3. فیلتر در سایدبار فروشگاه ظاهر می‌شود.

---

## عیب‌یابی

| مشکل | راه‌حل |
|------|---------|
| فونت نمایش داده نمی‌شود | فایل‌های woff2 را در `assets/fonts/vazirmatn/` قرار دهید |
| استایل‌ها اعمال نمی‌شوند | مطمئن شوید `assets/css/tailwind.css` موجود است |
| سبد کناری باز نمی‌شود | Console مرورگر را بررسی کنید، تداخل افزونه محتمل است |
| صفحه فروشگاه خالی است | صفحه «فروشگاه» را در WooCommerce → تنظیمات → پیشرفته تنظیم کنید |
